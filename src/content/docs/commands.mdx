---
title: Commandes et Touches
description: Liste des touches et commandes disponibles sur le serveur
---

Toutes les touches ci-dessous sont modifiables dans le jeu : **Paramètres → Configuration des touches → FiveM**.

| Touche | Action |
|--------|--------|
| `TAB` | Ouvrir l'inventaire |
| `B` | Ouvrir le coffre du véhicule le plus proche |
