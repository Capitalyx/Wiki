---
title: Commandes
description: Liste des commandes et touches disponibles sur le serveur
---

Liste des commandes de chat et raccourcis clavier disponibles pour tous les joueurs. Les touches sont modifiables dans le jeu : **Paramètres → Configuration des touches → Capitalyx**.

| Commande | Description |
|----------|-------------|
| `/skills` | Ouvrir le menu de compétences |
| `/setLang <en\|fr\|es\|de>` | Changer la langue |
| `/engine` | Allumer / éteindre le moteur du véhicule |
| `/clothes` | Ouvrir le menu de vêtements |
| `/custom` | Menu d'extras / personnalisation du véhicule |
| `/passive` | Activer / désactiver le mode passif |
| Touche `X` | Ouvrir la liste des joueurs en ligne |
| Touche `TAB` | Ouvrir l'inventaire (touche configurable) |
| Touche `T` | Ouvrir le chat — utilisez `TAB` pour naviguer entre les onglets |
