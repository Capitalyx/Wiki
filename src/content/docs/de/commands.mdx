---
title: Befehle
description: Liste der auf dem Server verfügbaren Befehle und Tasten
---

Liste der Chat-Befehle und Tastenkürzel, die allen Spielern zur Verfügung stehen. Die Tasten können im Spiel geändert werden: **Einstellungen → Tastenbelegung → Capitalyx**.

| Befehl | Beschreibung |
|--------|--------------|
| `/skills` | Fähigkeitenmenü öffnen |
| `/setLang <en\|fr\|es\|de>` | Sprache ändern |
| `/engine` | Fahrzeugmotor an-/ausschalten |
| `/clothes` | Kleidungsmenü öffnen |
| `/custom` | Menü für Fahrzeugextras / Anpassung |
| `/passive` | Passiven Modus aktivieren / deaktivieren |
| Taste `X` | Liste der Online-Spieler öffnen |
| Taste `TAB` | Inventar öffnen (Taste konfigurierbar) |
| Taste `T` | Chat öffnen — mit `TAB` zwischen den Tabs wechseln |
