---
title: Commands and Keybinds
description: List of commands and keybinds available on the server
---

List of chat commands and keyboard shortcuts available to all players. Keys can be changed in-game: **Settings → Key Bindings → FiveM**.

| Command | Description |
|---------|-------------|
| `/skills` | Open the skills menu |
| `/setLang <en\|fr\|es\|de>` | Change language |
| `/engine` | Turn the vehicle engine on / off |
| `/clothes` | Open the clothing menu |
| `/custom` | Vehicle extras / customization menu |
| `/passive` | Toggle passive mode |
| `X` key | Open the list of online players |
| `TAB` key | Open the inventory (key is configurable) |
| `T` key | Open the chat — use `TAB` to switch between tabs |
