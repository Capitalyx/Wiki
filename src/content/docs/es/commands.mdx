---
title: Comandos
description: Lista de comandos y teclas disponibles en el servidor
---

Lista de comandos de chat y atajos de teclado disponibles para todos los jugadores. Las teclas se pueden modificar en el juego: **Configuración → Configuración de teclas → FiveM**.

| Comando | Descripción |
|---------|-------------|
| `/skills` | Abrir el menú de habilidades |
| `/setLang <en\|fr\|es\|de>` | Cambiar el idioma |
| `/engine` | Encender / apagar el motor del vehículo |
| `/clothes` | Abrir el menú de ropa |
| `/custom` | Menú de extras / personalización del vehículo |
| `/passive` | Activar / desactivar el modo pasivo |
| Tecla `X` | Abrir la lista de jugadores en línea |
| Tecla `TAB` | Abrir el inventario (tecla configurable) |
| Tecla `T` | Abrir el chat — usa `TAB` para cambiar entre pestañas |
