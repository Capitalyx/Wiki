# Guía para Principiantes - Capitalyx

¡Bienvenido a Capitalyx! Esta guía te ayudará a dar tus primeros pasos en el servidor.

## <span class="heading-icon"><Icon name="rocket" /> Primeros Pasos</span>

- Descarga FiveM desde [fivem.net](https://fivem.net)
- Busca "Capitalyx" en la lista de servidores
- Únete al servidor

## Elegir un Trabajo

Consulta la página de [Trabajos](/es/jobs/) para descubrir todos los trabajos disponibles, cómo empezar y las tarifas actualizadas en directo desde el servidor.

## <span class="heading-icon"><Icon name="information" /> Ayuda y Soporte</span>

- **Discord**: Únete a nuestra comunidad
- **Soporte**: Contacta a los administradores
- **Wiki**: Explora esta documentación

Para la lista completa de comandos y atajos, consulta la página de [Comandos](/es/commands/).

¡Disfruta el juego en Capitalyx!
