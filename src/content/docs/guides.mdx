# Guide Débutant - Capitalyx

Bienvenue sur Capitalyx ! Ce guide vous aidera à faire vos premiers pas sur le serveur.

## <span class="heading-icon"><Icon name="rocket" /> Premiers Pas</span>

- Téléchargez FiveM depuis [fivem.net](https://fivem.net)
- Recherchez « Capitalyx » dans la liste des serveurs
- Rejoignez le serveur

## Choisir un Métier

Consultez la page [Métiers](/jobs/) pour découvrir tous les métiers disponibles, comment les débuter et leurs tarifs à jour en direct depuis le serveur.

## <span class="heading-icon"><Icon name="information" /> Aide et Support</span>

- **Discord** : Rejoignez notre communauté
- **Support** : Contactez les administrateurs
- **Wiki** : Explorez cette documentation

Pour la liste complète des commandes et raccourcis, consultez la page [Commandes](/commands/).

Bon jeu sur Capitalyx !
